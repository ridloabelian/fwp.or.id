## Aturan Penggunaan

1. Prioritaskan dokumentasi kamera untuk hero, berita utama, dan publikasi resmi.
2. Gunakan dokumentasi HP untuk update cepat dan konten pendukung.
3. Verifikasi subjek, kegiatan, tanggal, dan izin publikasi sebelum tayang.
4. Jangan mengandalkan salinan aset lokal sebagai versi terbaru; cek folder Drive terlebih dahulu.
5. Simpan aset terpilih secara lokal dengan nama deskriptif dan optimasi format/ukuran sebelum deploy.
